# PLANET-OPS
مشروع PLANET OPS هو لعبة مهمة فضائية تعليمية تفاعلية، يستكشف فيها اللاعب الفضاء والكواكب وينفذ مهامًا وتحديات باستخدام بيانات ناسا، مثل صور المريخ وبيانات الكواكب والكويكبات، بهدف تنمية المعرفة العلمية ومهارات التفكير وحل المشكلات. تقود الفريق شروق الحربي، وتضم نوادر الجابري، أروى الجهني، ريتاج المغذوي، وشيماء الحربي.
